# 📷 Разблокировка RTSP на камере V380 Pro

У V380 Pro поток RTSP/ONVIF **отключён производителем** — поэтому на вашей
камере закрыт порт 554. Открывается файлом-хаком на SD-карте.

## Что понадобится

- МикроSD-карта (любая, FAT32), картридер или слот телефона
- 10 минут времени

## Файлы

| Файл | Для каких прошивок |
|---|---|
| `ceshi.ini` | классические прошивки |
| `ceshi-new.ini` | свежие прошивки (2023+) — вариант `rtsp_enable=1` |

Если первый не сработал — попробуйте второй.

## Порядок действий

1. Скопируйте `ceshi.ini` **в корень** SD-карты (не в подпапку)
2. Выключите камеру из розетки
3. Вставьте SD-карту
4. Включите камеру и ждите ~5 минут (может говорить по-китайски — это норма)
5. Выключите, выньте карту, удалите с неё файл
6. Включите камеру

## Проверка

```sh
nmap -p 554 192.168.1.105        # порт должен стать open
```

Или в VLC: Медиа → Открыть URL:

```
rtsp://192.168.1.105:554/live/ch00_0     # SD-поток
rtsp://192.168.1.105:554/live/ch00_1     # HD-поток
rtsp://логин:пароль@192.168.1.105:554/live/ch00_0   # если требует логин/пасс
```

Другие пути, если основные не работают: `/onvif1`, `/h264_stream`,
`/Onvif/live/1/1`, `/ch0_0.h264`.

## Что это даёт боту

После включения RTSP поток можно смотреть в VLC с любого устройства.
Для команды `/cam` (снимок JPEG) нужен ffmpeg — он не влезает во flash
роутера, но можно поставить на старый телефон (Termux): он будет дёргать
кадр из RTSP и отдавать по HTTP для бота.

## ⚠️ Безопасность v380

Известно, что облачный протокол V380 передаёт логин/пароль в открытом виде,
а локальный RTSP иногда работает вообще без пароля. Смените пароль камеры
в приложении и не пускайте её в интернет без нужды.
